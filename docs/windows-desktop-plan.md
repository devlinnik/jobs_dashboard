# План доработки Windows-приложения

## Архитектура сборки — реализовано

- `dist/DevlinDesk/DevlinDesk.exe` — основной вход, с собственной иконкой.
- `runtime/` — Python, DLL, интерфейс и графические ресурсы.
- `maintenance/` — скрипты обновления и `install-info.json` формата 2.
- `Update-Devlin.cmd` и `README.txt` — доступные пользователю файлы рядом с EXE.
- `dist/backups/DevlinDesk-ДАТА-ИД/` — предыдущие версии, без автоматического удаления.
- Данные, ключи и журнал приложения остаются в `%LOCALAPPDATA%/DevlinDesk`.
- `dist` целиком исключён из Git. В Git хранятся код, ICO, исходник PNG и сборочные скрипты.

Новая установка принимает старый формат, проверяет новую сборку до замены и сохраняет старую целиком. При неудачной финальной замене выполняется откат. Первый переход выполняется через обновление исходников и корневой `Install-Devlin.cmd`.

При изменении упаковщика updater запускает обновлённый скрипт с подготовленными исходниками и метаданными. Блокировки отпускаются перед передачей управления, а временные исходники сохраняются до завершения дочернего сборщика. Ошибки дочерней сборки и передачи управления добавляются в общий диагностический журнал без потери исходной причины.

## Иконка — реализовано

Мятная монограмма D с графиком мониторинга, на графитовом фоне. PNG служит исходником; ICO содержит размеры 16, 24, 32, 48, 64, 128 и 256 px. PyInstaller встраивает ICO в EXE; pywebview на Windows извлекает иконку окна из EXE, ярлык ссылается на неё, pystray читает тот же ICO из ресурсов.

Проверка Windows-EXE сравнивает встроенные RT_GROUP_ICON/RT_ICON с исходным ICO для всех размеров и пикселей. Ярлык использует ICO напрямую. После установки Shell получает уведомления о замене файла и изменении кеша значков; корневой `Refresh-Icons.cmd` выполняет такое обновление без пересборки, перезапуска Проводника или удаления файлов системного кеша.

## Фоновый режим — реализовано

- Закрытие окна скрывает его, не останавливая локальный сервер и монитор.
- При первом скрытии показывается уведомление о работе в фоне.
- Обычный щелчок по значку открывает окно; правая кнопка показывает меню.
- Меню содержит последние статусы проектов, число проблем, сведения об изменённых Git-файлах и полный выход.
- Статусы обновляются каждые 10 секунд без дополнительных сетевых проверок.
- При настроенном PIN названия и результаты проектов в трее скрыты.
- Полный выход завершает GUI и трей, затем останавливает сервер, ожидая активных операций монитора.
- При отказе трея окно не остаётся недоступным; его закрытие завершает приложение.
- Обновление обнаруживает работающий процесс и предлагает выйти через трей; принудительного завершения нет.

## Проверка

В Linux проверены тестами скрытие/открытие/выход, реальная проверка монитора при скрытом окне, восстановление при отказе трея, защита сведений PIN, статусы и миграция сборки с сохранением старой версии. Проверены PowerShell-скрипты. `--self-test` дополнительно проверяет ресурсы иконки и на Windows — зависимости трея.

GitHub Actions выполняет сборку и проверку EXE на Windows. Нативная ручная проверка на Windows: запустить установленное приложение, закрыть крестиком, дождаться проверки проекта, открыть окно через значок, проверить меню, выйти через него и выполнить обновление. Этот сценарий нельзя считать пройденным на основании Linux-тестов.
